Проведи проверку перед демо. Адрес бэкенда: $ARGUMENTS (если пусто — прод https://deti.201-34-157-90.sslip.io/api; для локальной проверки передай http://localhost:8000).

1. `make lint` и `make test` — покажи итог (сколько тестов, есть ли ошибки).
2. `bash scripts/smoke_test.sh <адрес>` — покажи вывод. Если упал — найди причину: локально `docker compose logs --tail=50 backend`, на проде — последняя выкладка (`gh run list --workflow deploy.yml --limit 3`, `gh run view <id> --log-failed`). Ничего не чини без подтверждения.
3. `curl <адрес>/health` — какой провайдер и модель реально используются. Если `fake` — громко предупреди: на демо нужен настоящий LLM.
4. `git status`, `git log -1 origin/main` и последняя зелёная выкладка (`gh run list --workflow deploy.yml --status success --limit 1`) — всё ли закоммичено, запушено и выложено именно то, что покажем.
5. Пройди по `docs/DEMO_CHECKLIST.md`: то, что можно проверить командой, проверь сам; остальное выведи списком «проверить руками».

Итог — таблица `пункт | ✅/❌/❓ | комментарий` и список того, что нужно сделать до выхода на сцену.
