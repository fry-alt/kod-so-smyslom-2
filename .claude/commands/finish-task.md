Работаем по [docs/WORKFLOW.md](../../docs/WORKFLOW.md). Текущая задача — из имени ветки (`a/T-NN-…` / `b/T-NN-…`).

1. Найди Issue: `gh issue list --search "T-NN in:title" --state open`. Перечитай «Готово, когда».
2. Проверь по-настоящему:
   - `make lint && make test` — оба должны пройти;
   - руками каждый пункт «Готово, когда» (Swagger `/docs`, curl или браузер). Не прошло — чини, не сдавай.
3. Проверь, что имя, контакт, `telegram_id` и заметки координатора не попадают в промпты и в индекс (если задача касалась LLM).
4. Создай заметку `docs/changes/<сегодня ГГГГ-ММ-ДД>-<логин из gh api user -q .login>-T-NN-<коротко>.md`
   по `docs/changes/_TEMPLATE.md`: по-русски, коротко, для человека, который работу не видел.
   Если поменял то, что описано в чужой заметке, — упомяни это.
5. Коммит (без любой атрибуции Claude), `git push -u origin HEAD`,
   `gh pr create` с заголовком `T-NN: <что сделано>` и телом по `.github/pull_request_template.md`, первой строкой `Closes #<N>`.
   Если менялись `schemas.py` / `api.ts` — метка `контракт` и отметь напарника в описании.
6. `gh pr checks --watch`. Красный — разберись и почини. Зелёный:
   - метки `контракт` нет → `gh pr merge --squash --delete-branch`;
   - метка `контракт` есть → скажи пользователю, что ждём 👍 напарника, и не мержь.
7. `git checkout main && git pull`. Коротко отчитайся: что сделано, ссылка на PR, что дальше (`/take-task`).
