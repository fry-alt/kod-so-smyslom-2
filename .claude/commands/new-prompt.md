Создай промпт по описанию: $ARGUMENTS

1. Файл `backend/app/llm/prompts/<имя>.md`. Переменные — `$name` (подставляются через `load_prompt("<имя>", name=...)`, `string.Template`). Фигурные скобки JSON экранировать не нужно.
2. Структура промпта:
   - роль и задача в 1–2 предложениях;
   - правила (что делать при нехватке данных — честно сказать, не выдумывать);
   - 2–3 few-shot примера «вход → JSON-ответ», разные по сложности, один — пограничный случай;
   - в конце блок с входными данными через переменные.
3. Pydantic-модель ответа рядом с кодом, который вызывает промпт (обычно `backend/app/services/...`), у каждого поля — `Field(description=...)`. JSON-схему в промпт вставлять не надо: `get_llm().chat_json(prompt, Model)` добавляет её сам, валидирует ответ и делает 1 повтор при невалидном JSON.
4. Тест в `backend/tests/`: промпт загружается со всеми переменными, `chat_json` на провайдере `fake` возвращает валидную модель.
5. Покажи, как вызвать промпт из сервиса (3–5 строк кода).

Пиши промпт по-русски, конкретно, без «ты — лучший в мире эксперт».
