# Питч: 7 слайдов

> Регламент обычно 5–7 минут + вопросы. Один слайд ≈ 1 минута. Демо — вживую, видео — запасной план.

## 1. Проблема
- Одна фраза: кому и что сейчас мешает.
- Цифра от заказчика (часы, обращения, потери).

## 2. Пользователь
- Конкретный человек: роль, день, где сейчас делает работу.
- Цитата / наблюдение от НКО, если есть.

## 3. Решение
- Одной фразой: «Бот/приложение, которое … за … вместо …».
- Скриншот главного экрана.

## 4. Демо
- Один сквозной сценарий от начала до конца, без отвлечений.
- Заранее подготовленные вопросы/данные. Ссылка/QR для жюри.

## 5. Как работает AI
- Схема из `docs/ARCHITECTURE.md` (упрощённая): данные НКО → поиск → LLM → ответ с источниками.
- Какая модель и почему (российский провайдер, стоимость, данные не уходят за рубеж и т.п.).
- Как боремся с галлюцинациями: ответ только по документам, «не знаю», цитаты, валидация JSON.

## 6. Эффект
- Было → стало (время, качество, охват). Как посчитали.
- Что получает НКО уже завтра.

## 7. Внедрение
- Что нужно, чтобы запустить у заказчика: сервер/облако, ключ, кто поддерживает.
- Стоимость в месяц (оценка токенов).
- Следующие шаги и что сделали бы ещё с неделей времени.
