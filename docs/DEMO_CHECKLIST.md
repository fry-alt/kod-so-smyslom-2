## Если что-то упало
| Что | Что делаем |
|---|---|
| Сайт не открывается | Видео-запас; параллельно `gh run list --workflow deploy.yml` — не идёт ли выкладка |
| Поиск отвечает «оценка без AI» | Продолжаем: это и есть фолбэк, проговорить «модель недоступна — поиск всё равно работает» |
| Бот молчит | Открыть сайт на телефоне напрямую — тот же интерфейс |
| Интернет площадки | Раздача с телефона, затем видео |
