# Лента сцен на главной, «Спросить о фонде» в новом виде, правки звонка

## Что изменилось
- **Главная:** вместо сетки 2×2 — 3D-бегущая лента из 12 анимированных сцен «чем помогают волонтёры» (мастер-классы, наставничество, специалисты, ярмарки и фото, ведение занятий, валяние, кулинария, выезды, онлайн-помощь, водитель, медиатор на выставке, обучение). Три колонки едут в разные стороны, в кадре нет повторов, края плавно растворяются в фон, при наведении не останавливается. Без библиотек — CSS и SVG; при «уменьшении движения» стоит на месте; для экранных чтецов — скрытый список направлений.
- **«Спросить о фонде»:** широкая раскладка, как у главной; поле ввода и «Спросить» объединены в gooey-поле (при вводе расходятся «тягучей» анимацией). Вопросы по документам и чат работают как раньше.
- **Звонок:** во время звонка поверх видео больше нет плашки с логотипом (у волонтёра и координатора). После «Завершить звонок» вопросы и форма итога у координатора — по центру экрана широкой колонкой, а не в боковой панели.

## Где в коде
- `miniapp/src/screens/volunteer/VolunteerScenes.tsx` — сцены и лента; `miniapp/src/index.css` — стили `marquee3d-*`, `anim-*`, gooey.
- `miniapp/src/screens/volunteer/Ask.tsx`, `miniapp/src/App.tsx` (`/ask` в широких страницах).
- `miniapp/src/call/CallScreen.tsx`, `miniapp/src/call/CoordinatorPanel.tsx`.
- Контракт и бэкенд не менялись, зависимостей нет.

## Как проверить
`VITE_MOCK=1 make dev-miniapp` → `/` (лента), `/ask` (gooey-поле, обе вкладки). Звонок — на живом бэкенде: координатор завершает звонок → форма итога по центру. `npm run build` проходит.
