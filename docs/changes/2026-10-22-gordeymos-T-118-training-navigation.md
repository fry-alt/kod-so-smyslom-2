# Сохранить путь обучения и сделать навигацию ссылками

## Что изменилось
- Открытый модуль и тест обучения отражаются в URL и восстанавливаются после перезагрузки.
- Внутренние страницы волонтёра получили единый переход в личный кабинет.
- Навигационные переходы используют ссылочный компонент с настоящими `href`.

## Где в коде
- `miniapp/src/App.tsx`, `screens/volunteer/Training.tsx`, `Interview.tsx`, `Me.tsx`, `screens/admin/Search.tsx`, `ui.tsx`.

## Как проверить
- `npm run build` — успешно.
- `make lint` и `make test` — прошли по результатам проверки ветки.
- В preview проверить прямую загрузку URL обучения, обновление страницы, браузерный «Назад» и открытие ссылки в новой вкладке.
