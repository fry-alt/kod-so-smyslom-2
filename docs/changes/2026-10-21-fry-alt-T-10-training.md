# Обучение волонтёров работает: модули → тест от LLM → проверка → статус и балл

## Что изменилось
- Волонтёр получает список учебных модулей, по каждому — тест из 5 вопросов с 3–4 вариантами. Тест составляет LLM по тексту модуля один раз, дальше он берётся из базы.
- После сдачи волонтёр видит балл и какие ответы верные. Модуль сдан от 70%.
- Статус меняется сам: первая попытка — `new → training`, все **обязательные** модули сданы — `→ trained`. Дополнительный модуль («Как стать значимым взрослым») идёт в балл, но на статус не влияет. Статусы координатора (`approved`, `active`, `paused`) тест не трогает.
- Балл волонтёра (`training_score`) — среднее лучших попыток по модулям (функция из T-01, не менялась).
- Если LLM недоступна или ответила мусором — берётся готовый тест из `data/training/<id>.quiz.json`. Такие файлы написаны для всех 4 модулей, поэтому на `fake` и при сбое сети обучение тоже работает.

## Где в коде
- Новые эндпоинты (контракт `schemas.py` не менялся — схемы `TrainingModule`, `Quiz`, `QuizSubmit`, `QuizResult` уже были):
  - `GET /training` — модули;
  - `GET /training/{module_id}/quiz` — тест без правильных ответов (404 — нет модуля, 502 — нет ни LLM, ни файла);
  - `POST /training/submit` — проверка, попытка сохраняется в `QuizAttempt`.
- `backend/app/services/training.py` — генерация, кэш в `QuizCache`, фолбэк, проверка, статусы. Внутренняя схема `QuizItem` = `QuizQuestion` + `correct` — только для LLM и БД, клиенту не уходит.
- `backend/app/api/training.py`, регистрация роутера в `main.py`.
- `backend/app/llm/prompts/quiz.md` — промпт с примером. В LLM уходит только текст модуля — данных волонтёра там нет.
- `data/training/0N-*.quiz.json` — готовые тесты по черновикам модулей из T-03.
- После смены статуса обновляются метаданные волонтёра в векторном индексе — поиск видит `trained`.

## Как проверить
- `make dev` → `/docs`: `GET /training` → `GET /training/01-about/quiz` → `POST /training/submit` с `volunteer_id` из `POST /volunteers` → `GET /volunteers/{id}`: статус и `training_score`.
- `make test` — `backend/tests/test_training.py`: кэш (LLM вызывается один раз), ответы скрыты, баллы, все переходы статусов, дополнительный модуль, статус координатора не перетирается, фолбэк при сбое и при невалидном ответе LLM, валидность готовых `.quiz.json`.

## Что осталось и на что обратить внимание
- Тест кэшируется навсегда. Фонд поменял текст модуля — удалите строку модуля из таблицы `quizcache` (и поправьте `.quiz.json`), тест составится заново. Тест, взятый из файла, тоже кэшируется — чтобы проверка шла по тем же вопросам, что видел волонтёр.
- Пришлют настоящие материалы фонда (см. заметку T-03) — переписать и `.quiz.json`.
