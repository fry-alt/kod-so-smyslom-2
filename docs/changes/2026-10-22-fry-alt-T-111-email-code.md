# Подтверждение почты кодом при регистрации — схема из Yapp

## Что изменилось
- Регистрация теперь в два шага: форма → на почту приходит 6-значный код → аккаунт создаётся только после верного кода.
  Пока код не введён, заявка (почта, хэш пароля, роль) лежит в таблице `emailcode`, аккаунта нет и войти нельзя.
- Код живёт 15 минут, 5 попыток, «Отправить ещё раз» — через минуту. Действуют три последних кода: письма приходят
  с задержкой, и подойдёт код из прошлого письма. Храним только хэш кода. Не больше 10 писем в час с одного IP.
- На сайте — шаг «Подтвердите почту»: крупное поле для кода (шесть цифр — проверяется сам), «Отправить ещё раз» с
  отсчётом, «Изменить почту» — назад к форме с заполненными полями.
- Письма уходят через Yandex Cloud Postbox Yapp: на проде ключ и адрес берутся из `/opt/yapp/.env` прямо на сервере
  (как TURN). Отправитель — «Дети Марии <адрес Yapp>». **Нет ключа Postbox — регистрация идёт по-старому, без кода**,
  чтобы выкладка не закрыла регистрацию. Локально код печатается в лог бэкенда.

## Где в коде
- `backend/app/services/email_codes.py` (новый) — выдача и проверка кодов, письмо; перенос `server/email-codes.js` Yapp.
- `backend/app/services/mail.py` (новый) — отправка через Postbox, подпись AWS SigV4 без SDK (перенос `mail.js`,
  `sigv4.js`; подпись сверена с Yapp в тесте), `enabled()`, `set_mailer()` для тестов.
- `backend/app/services/accounts.py` — `register` разделён на `prepare` (проверка) и `create` (запись).
- `backend/app/models.py` — таблица `EmailCode`. Миграция не нужна: новая таблица создаётся сама.
- **Контракт API:** `POST /auth/register` отвечает `CodeSent {pending, email, resend_after}` (или `AuthOut`, если почта
  на сервере не настроена); новые `POST /auth/register/resend {email}` → `CodeSent`,
  `POST /auth/register/verify {email, code}` → `AuthOut`. `miniapp/src/api.ts` — `CodeSent`, `authApi.resend/verify`.
- `miniapp/src/screens/Auth.tsx` — шаг `CodeStep`; `miniapp/src/mock.ts` — в моках код всегда `123456`.
- Переменные: `POSTBOX_KEY_ID`, `POSTBOX_SECRET`, `MAIL_FROM`, `MAIL_LOG_CODES` (`.env.example`).
  `deploy/mail-from-yapp.sh` (новый) и `deploy.yml` — ключ из `.env` Yapp, `MAIL_LOG_CODES=false` на проде.

## Как проверить
- `make test` — `backend/tests/test_email_codes.py`: аккаунт только после кода, одноразовость, 5 попыток, 15 минут,
  повтор через минуту и три действующих кода, ошибка отправки, лимит писем с IP, прод без почты, подпись SigV4,
  кодировка имени отправителя, запрос в Postbox. `test_auth.py` регистрирует через код.
- Локально `make dev` + `make dev-miniapp` → `/login` → регистрация → код в логе бэкенда → личный кабинет.
- На проде после выкладки в логе деплоя: «Почта: коды подтверждения уходят с …» или «…регистрация без кода».

## Что осталось и на что обратить внимание
- Письма идут с домена Yapp (`yyaapp.ru`) — подписано «Дети Марии». Для настоящего фонда нужен свой домен в Postbox.
- «Забыли пароль?» из Yapp не переносили — можно сделать тем же `email_codes.py`.
- Уже зарегистрированных не трогаем.
