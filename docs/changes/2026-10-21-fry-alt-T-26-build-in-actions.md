# T-26: образы собираются в GitHub Actions, а не на сервере

## Что изменилось
- Выкладка собирает `deti-python` и `deti-miniapp` на машине GitHub (с кешем слоёв) и загружает на сервер
  через `docker save | ssh docker load`. Сервер ничего не скачивает и не компилирует.
- На сервер из репозитория теперь едет только `data/`; папки `~/deti/src` и `~/deti/.docker` больше не нужны и удаляются.

## Зачем
Первая сборка на сервере (1 ядро, медленный Docker Hub из РФ) висела больше 25 минут, её пришлось отменить.
Заодно сборка больше не грузит сервер, на котором живёт Yapp.

## Где в коде
`.github/workflows/deploy.yml` (шаги сборки и «Образы и данные на сервер»), `deploy/docker-compose.prod.yml`
(`image: … pull_policy: never` вместо `build`), README.

## Как проверить
Actions → Deploy зелёный, `https://deti.201-34-157-90.sslip.io/api/health` отвечает.

## Что осталось и на что обратить внимание
Секреты и переменные из T-12 (отдельные ключи вместо `APP_ENV`) не тронуты.
