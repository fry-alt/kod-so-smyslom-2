# Поле кода из письма — шесть ячеек

## Что изменилось
- На шаге «Подтвердите почту» вместо одного поля с точками — шесть ячеек. Цифры крупные, шрифтом сайта (Onest),
  одинаковой ширины; в следующей ячейке мигает курсор, набранная цифра мягко «появляется».
- Пока код проверяется, по ячейкам бежит волна; неверный код — ячейки вздрагивают и очищаются.
- Под ячейками лежит настоящее прозрачное поле: работают вставка из буфера и подстановка кода на телефоне.
  При «уменьшить движение» в системе анимаций нет.

## Где в коде
- `miniapp/src/screens/Auth.tsx` — компонент `CodeCells`, его использует `CodeStep` (заметка `2026-10-22-fry-alt-T-111-email-code`).

и на ширине телефона (375 px): ввод, неверный код, верный код → личный кабинет.
