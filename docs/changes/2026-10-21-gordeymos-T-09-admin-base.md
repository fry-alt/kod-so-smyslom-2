# Кабинет фонда: база волонтёров и карточка волонтёра со статусом, часами и заметками

## Что изменилось
- **База** (`/admin/volunteers`): на ноутбуке — таблица (имя, статус цветной меткой, навыки из профиля, когда может, балл обучения, часы), на телефоне — карточки без горизонтальной прокрутки. Фильтр по статусу — крупные кнопки, «Все» по умолчанию. Клик по строке открывает карточку.
- **Карточка** (`/admin/volunteers/:id`): ответы анкеты, профиль от AI (резюме, навыки, интересы, подходящие роли — названиями из `/roles`; если профиля нет — «AI ещё не разобрал анкету»), балл обучения, контакт с кнопками «Копировать» и «Написать в Telegram».
- Координатор может сменить статус кнопками «Допустить» / «Активен» / «Пауза», записать часы (можно с запятой: `2,5`) и добавить заметку. Всё сохраняется на сервере и видно после перезагрузки.
- Заметки — лента, новые сверху, с автором и датой. Имя автора необязательное и запоминается в браузере.
- Пустой список, ошибка сети и несуществующий волонтёр — понятным текстом.

## Где в коде
- `miniapp/src/screens/admin/Volunteers.tsx` — база: фильтр, таблица (`lg:` и шире) и карточки (уже `lg`).
- `miniapp/src/screens/admin/VolunteerCard.tsx` — карточка: блоки «Статус», «Часы», «Обучение», «Заметки», «Профиль от AI», «Ответы анкеты».
- `miniapp/src/ui.tsx` — сюда переехал `Contact` из `Search.tsx` (общий для поиска и карточки); у `Badge` появился необязательный `title`.
- Контракт API не менялся, новых зависимостей нет. Используются `backend.list / get / update / notes / addNote / roles`.

## Как проверить
1. Бэкенд: `uv sync`, `.venv/bin/uvicorn app.main:app --port 8001 --app-dir backend`, `BACKEND_URL=http://localhost:8001 make seed`.
2. Фронт: `cd miniapp && BACKEND_URL=http://localhost:8001 npm run dev`, открыть `/admin/volunteers`.
3. Фильтр «Активен» → «Волонтёров со статусом «Активен» нет»; «Все» → 40 анкет.
4. Открыть человека → «Допустить», часы `12,5` → «Сохранить», добавить заметку → перезагрузить страницу: статус «Допущен», часы 12,5, заметка на месте; в базе у него тоже «Допущен» и 12,5.
5. Ширины 1280, 1024 и 375 px — без горизонтальной прокрутки. На моках (`VITE_MOCK=1`) экраны тоже работают.

Проверено руками на живом бэкенде (SQLite) и на моках; `npm run build` и `make lint` проходят. Автотестов фронта в проекте нет.

## Что осталось и на что обратить внимание
- На провайдере `fake` навыки в профиле — длинные строки-заглушки; в базе метки обрезаются до двух строк (полный текст — в подсказке и в карточке). С настоящим LLM будут короткие теги.
- Статусы «Новая анкета», «Проходит обучение» и «Обучение пройдено» вручную не ставятся — их выставляет само обучение (тесты волонтёра). Кнопками — только «Допустить», «Активен», «Пауза», как в Issue.
