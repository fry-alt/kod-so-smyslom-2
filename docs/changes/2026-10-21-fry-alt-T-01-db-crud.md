# Волонтёры в базе: анкета, статус, часы, заметки координатора и справочник ролей — без LLM

## Что изменилось
- Анкету можно сохранить: `POST /volunteers` создаёт волонтёра со статусом `new`, профиль пока пустой (`profile: null`) — его заполнит LLM в T-05.
- Координатор видит список (`GET /volunteers`, новые сверху, фильтр `?status=approved`), карточку (`GET /volunteers/{id}`) и меняет статус и часы (`PATCH /volunteers/{id}`, меняются только переданные поля).
- История взаимодействия: `GET/POST /volunteers/{id}/notes`.
- `GET /roles` отдаёт роли из `data/roles.json`; пока файла нет (T-03) — пустой список.
- Неизвестный id → 404 с понятным текстом.

## Где в коде
- `backend/app/models.py` — новые таблицы: `Volunteer` (ответы анкеты и профиль — JSON), `Note`, `QuizCache` (тест по модулю с правильными ответами, для T-10), `QuizAttempt` (попытки теста).
- `backend/app/services/volunteers.py` — вся логика; `to_out()` собирает `VolunteerOut`, `training_score` = среднее **лучших** попыток по каждому модулю (None — не проходил).
- `backend/app/services/roles.py` — `load_roles()`; пригодится в T-05 (подсказать LLM роли) и T-06.
- `backend/app/api/volunteers.py`, `backend/app/api/roles.py` — тонкие обёртки, подключены в `main.py`.
- Контракт (`schemas.py`) не менялся. Новых зависимостей и переменных окружения нет.

## Как проверить
- `make dev` → http://localhost:8000/docs: создать волонтёра, поменять статус и часы, добавить и прочитать заметку, открыть `/roles`.
- `make test` — `backend/tests/test_volunteers.py`: создание и чтение, валидация анкеты, 404, фильтр по статусу, частичное обновление, заметки, расчёт балла, роли из файла.
