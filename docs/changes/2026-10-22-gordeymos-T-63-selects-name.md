# Свои выпадающие списки, заливка на всех кнопках, имя при регистрации

## Что изменилось
- Компонент `Select` в `ui.tsx` — выпадающий список в стиле сайта вместо системного. На нём роль в умном поиске и остальные списки кабинета: «Регион» и «Когда может» в «Базе», условия поиска.
- Анимация заливки `btn-flair` у кнопок «Войти», «Выйти», «Личный кабинет» и у кнопок в «Спросить о фонде».
- При регистрации обязательно поле «Как вас зовут». В кабинете и шапке показывается имя вместо почты, анкета подставляет его сама. У старых аккаунтов имени нет, у них до этой правки была видна почта.
- Почту вместо имени больше нигде не показываем: у старых аккаунтов без имени — имя из анкеты, иначе «Координатор» / «Волонтёр» (почта — только в подсказке); имя в шапке освежается через `auth.me()` при открытии сайта; мок-аккаунты `coord@demo.test` и др. получили вымышленные имена (`accountName` в `backend.ts`, `DEMO_NAMES` в `mock.ts`).
- **Контракт API:** в `RegisterIn` добавлено обязательное поле `name`, в `AccountOut` — поле `name` (пусто у старых аккаунтов). Таблица аккаунтов получила столбец `name`: `db.py` добавляет его в существующую базу при запуске.

## Где в коде
- `miniapp/src/ui.tsx` (`Select`), `screens/admin/Search.tsx`, `screens/admin/Volunteers.tsx`, стили в конце `index.css`.
- `miniapp/src/App.tsx`, `screens/Auth.tsx`, `screens/volunteer/Me.tsx`, `Form.tsx`, `Ask.tsx`.
- `backend/app/schemas.py`, `models.py`, `db.py`, `services/accounts.py`, тесты `test_auth.py` и `test_email_codes.py`; `miniapp/src/api.ts`, `backend.ts`, `mock.ts`.

## Как проверить
- `uv run pytest backend/tests` — все тесты проходят; `cd miniapp && npm run build` — успешно.
- `/login`: регистрация без имени не проходит, после регистрации в шапке имя.
- `/admin/search` и `/admin/volunteers`: списки открываются, выбор фильтрует.
