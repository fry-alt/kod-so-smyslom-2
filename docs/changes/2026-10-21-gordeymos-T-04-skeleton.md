# Каркас приложения: маршруты волонтёра и кабинета фонда, моки по контракту, крупный дизайн

## Что изменилось
- Демо-экраны шаблона убраны. Одно приложение — две части: `/` — волонтёр, `/admin` — кабинет фонда.
- Волонтёр: `/` приветствие → `/form` анкета → `/me` статус → `/training` обучение, `/opportunities` возможности, `/ask` «Спросить о фонде» (чат и вопросы по документам из шаблона).
- Фонд: `/admin` умный поиск, `/admin/volunteers` база, `/admin/volunteers/:id` карточка, `/admin/opportunities` возможности.
- Экраны пока — заглушки с пометкой задачи (T-07, T-08, T-09, T-11, T-23), но уже ходят в API и показывают данные, чтобы было видно, что моки и маршруты работают.
- Дизайн: базовый шрифт 18px, кнопки высотой от 48px, тёплая палитра фонда; в Telegram — цвета темы пользователя.

## Где в коде
- `miniapp/src/router.ts` — маршрутизация без библиотек (`usePath`, `navigate`, `match`).
- `miniapp/src/backend.ts` — **экраны берут API отсюда**: `backend` (настоящий `volunteersApi` или моки), `chatApi`, `getVolunteerId/setVolunteerId` (localStorage).
- `miniapp/src/mock.ts` — все функции `volunteersApi` на вымышленных данных: 10 волонтёров, 6 ролей (по направлениям из анкеты фонда), 3 модуля обучения, 3 возможности; поиск по ключевым словам с оценками. Данные в памяти, после перезагрузки сбрасываются.
- `miniapp/src/labels.ts` — русские подписи для значений контракта (статусы, время, регионы, формат…).
- `miniapp/src/ui.tsx` — общие элементы: `Button`, `Link`, `Card`, `Badge`, `Field`, `ErrorBox`, `Loading`, `useLoad`.
- `miniapp/src/App.tsx` — таблицы маршрутов и раскладки; `miniapp/src/screens/{volunteer,admin}/` — экраны.
- Контракт (`api.ts`) не менялся. Новых зависимостей нет.

## Как проверить
```bash
cd miniapp && VITE_MOCK=1 npm run dev
```
Открыть http://localhost:5173 — «Стать волонтёром» → «Отправить пример анкеты» → статус с тегами.
http://localhost:5173/admin — нажать пример запроса, появятся кандидаты; клик по имени → карточка.
Перезагрузка на `/admin/volunteers/3` не ломается. `npm run build` проходит.
