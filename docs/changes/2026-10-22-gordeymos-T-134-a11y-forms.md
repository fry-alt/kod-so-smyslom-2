# Доступность: варианты выбора на настоящих radio/checkbox, ошибки с фокусом, значки вместо эмодзи, различимые статусы

По юзабилити-аудиту: UX-16, UX-18, UX-22, UX-25, UX-37.

## Что изменилось
- Варианты выбора (анкета, роль при регистрации, тест обучения, оформление кабинета, фильтры и `Chips` в кабинете фонда) — настоящие `radio` и `checkbox` внутри `label`: стрелки переключают вариант, Tab заходит в группу один раз, у групп есть имя. Внешне и по анимациям — как раньше (заливка `btn-flair` при наведении осталась), рамка фокуса — на карточке варианта.
- Прогресс анкеты на телефоне: «Шаг N из 6» читается скринридером (`aria-live`), полоска — только картинка; переходы к пройденным шагам — кнопки высотой 44 px (визуально та же полоска). `role="progressbar"` с кнопками внутри больше нет.
- Ошибки анкеты и входа: фокус переходит в первое поле с ошибкой, у поля `aria-invalid` и `aria-describedby` на текст ошибки; ошибка согласия — с `role="alert"`. То же для кода из письма.
- Эмодзи-значки заменены на SVG в духе Lucide (`⚠️` в ошибках, часы, шапочка, календарь, замок, «👀» в плане собеседования, значки шагов и вариантов анкеты, роли при регистрации, подготовка к собеседованию). Галочки «✓» рядом с текстом скрыты от скринридера. Эмодзи аватаров и стикеров не трогали.
- Статусы волонтёров разведены по этапам и пронумерованы 1–5: голубой «Новая анкета», сиреневый «Проходит обучение», бирюзовый «Обучение пройдено», светло-зелёный «Допущен», насыщенный зелёный «Активен», серый «На паузе». Персиковый остался только для срочного в сводке.
- Заголовки без пропуска уровней: карточки на `/opportunities` — `h2` (внутри разделов «Вас приглашают» / «Все возможности» — `h3`), разделы учебных модулей — `h2`.

## Где в коде
- `miniapp/src/icons.tsx` — новый: набор значков и компонент `Icon` (без новых зависимостей).
- `miniapp/src/ui.tsx` — `Chips` на нативных input (новый необязательный `label` — имя группы), `Field group` — `role="group"` с подписью, `ErrorBox` с `id` и SVG-значком, новый `StatusBadge` (номер этапа + название).
- `miniapp/src/labels.ts` — `STATUS_COLOR` на переменных `--status-*`, новый `STATUS_STEP`.
- `miniapp/src/index.css` — переменные `--status-*`; рамка фокуса для `label` со скрытым input.
- `screens/volunteer/Form.tsx` — `Progress`, `Question` (`errorId`), `Choices`, фокус в `showErrors`.
- `screens/Auth.tsx` — роль на radio, поле с ошибкой получает фокус и `aria-invalid`.
- `screens/volunteer/training/QuizView.tsx`, `Markdown.tsx`, `Training.tsx`, `Look.tsx`, `Opportunities.tsx`, `Interview.tsx`, `History.tsx`, `Ask.tsx`, `Messages.tsx`, `messages/Thread.tsx`, `screens/admin/*` (Search, Volunteers, VolunteerCard, OpportunityCard, Summary, interview/Plan) — значки и `StatusBadge`.

## Как проверить
`cd miniapp && VITE_MOCK=1 npm run dev`:
- `/form` (после регистрации): пустое «Начнём →» — фокус в поле имени, ошибка читается; на шаге «О жизни» стрелки меняют занятость, Tab переходит к региону; на «Проверке» без согласия — фокус на флажке.
- `/form` без входа (экран регистрации): стрелки переключают «Я волонтёр / Я координатор»; кривая почта — фокус в поле почты.
- Тест обучения: стрелки выбирают ответ, группа названа текстом вопроса.
- `/admin/volunteers`: статусы разного цвета с номером этапа; фильтр «Статус» переключается стрелками, при наведении заливается как раньше.
Тестов на фронт нет; `npm run build` проходит.
