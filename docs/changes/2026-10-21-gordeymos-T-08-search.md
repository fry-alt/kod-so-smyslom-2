# Экран «Умный поиск» в /admin: запрос словами, «Как я понял запрос», карточки кандидатов, приглашения

## Что изменилось
- `/admin` — большая строка «Кого ищем?», 4 примера запросов кнопками, кнопки ролей из `/roles` («Или найти под роль»; без ролей строка скрыта).
- «Как я понял запрос» — чипсы из `parsed`: навыки, время, разово/постоянно, регион, формат, `notes`.
- Карточки кандидатов: оценка 0–100 с цветной полоской, причина, совпавшие навыки, статус (цветная метка), балл за обучение, время, род занятий, регион, контакт («Копировать», «Написать в Telegram» для @ника), пометка «Оценка без AI» при `ai=false`. Клик → карточка волонтёра.
- Фильтр «Показывать только» по статусам — сразу перезапускает последний поиск. Пусто — все, кроме «на паузе».
- Подбор под возможность: `/admin?opportunity=3` — заголовок с датой и местом, поиск с `opportunity_id` запускается сам, у карточек кнопка «Пригласить», внизу панель «Пригласить выбранных» → `invite`. Уже приглашённые помечены.
- После поиска страница сама прокручивается к результатам. Пустой результат и ошибки — понятным текстом (пока `/search` нет на бэкенде — «Эта функция на сервере ещё не готова»).

## Где в коде
- `miniapp/src/screens/admin/Search.tsx` — экран целиком (`Results`, `ParsedChips`, `CandidateCard`, `Contact`).
- `miniapp/src/router.ts` — `useSearchParam()` для `?opportunity=`.
- `miniapp/src/mock.ts` — мок-поиск понимает `opportunity_id` (строит запрос из возможности, как бэкенд).
- `miniapp/src/screens/admin/Opportunities.tsx` — временная ссылка «Подобрать волонтёров →» (полный экран — T-23).
- `miniapp/src/ui.tsx` — текст ошибки для 404.
- Контракт не менялся, зависимостей нет.

## Как проверить
- `VITE_MOCK=1 make dev-miniapp` → http://localhost:5173/admin → «Фотограф на четверг утром, разово»: чипсы «фотография · Будни, утро · Разово», сверху Ольга Зайцева 90.
- Отметить «Обучение пройдено» — остаются только такие.
- «Возможности» → «Подобрать волонтёров →» у фотосъёмки → выбрать кандидата → «Пригласить выбранных» → метка «Приглашён».
- Проверено на 1280 и 1024px; `npm run build` проходит.
