# Экраны возможностей: лента и «Моя история» у волонтёра, создание и участники в /admin

## Что изменилось
- **Волонтёр, `/opportunities`:** приглашения координатора сверху («Подтвердить участие» / «Не смогу»), ниже — лента по дате:
  дата и время, место/регион, формат, сколько мест осталось, часы, метка «Подходит вам», кнопка «Откликнуться».
  После действия — понятное сообщение сверху («✓ Вы записаны…»). Без анкеты — предлагаем заполнить `/form`.
- **Волонтёр, `/history` («Моя история»):** сумма часов за участие и все отклики/приглашения/участия со статусами.
  На «Моём статусе» — блок «Вас пригласили» и кнопка «Моя история и часы»; в шапке — пункт «Куда пойти».
- **Фонд, `/admin/opportunities`:** список по дате, «+ Создать возможность», на каждой — «Участники» и «Подобрать».
- **Фонд, `/admin/opportunities/new`:** форма `OpportunityIn`; выбор роли из `/roles` подставляет название, описание,
  формат и регион. Ошибки — рядом с полем, страница прокручивается к первой.
- **Фонд, `/admin/opportunities/:id`:** участники со статусами и кнопками «Подтвердить» / «Участвовал» / «Отказ»,
  счётчики (нужно, подтвердили, приглашены, откликнулись, участвовали), «Подобрать волонтёров» → `/admin?opportunity=<id>`
  (готовый подбор и «Пригласить выбранных» из T-08).

## Где в коде
- `miniapp/src/screens/volunteer/Opportunities.tsx`, `History.tsx` (новый), `Me.tsx` — экраны волонтёра.
- `miniapp/src/screens/admin/Opportunities.tsx`, `OpportunityForm.tsx` (новый), `OpportunityCard.tsx` (новый).
- `miniapp/src/App.tsx` — маршруты `/history`, `/admin/opportunities/new`, `/admin/opportunities/:id`, пункт «Куда пойти»;
  шапка волонтёра переносится целыми пунктами на узком экране.
- `miniapp/src/labels.ts` — `PARTICIPATION_COLOR`; `miniapp/src/ui.tsx` — `formatWhen`, `formatHours` (добавлены в конец).
- `miniapp/src/mock.ts` — возможности и участия теперь сохраняются в localStorage (`mock_opportunities`,
  `mock_participations`) и перечитываются при каждом вызове: путь «пригласить в /admin → подтвердить у волонтёра»
  переживает перезагрузку и работает в двух вкладках. Повторный отклик/приглашение не создаёт дубль.
- Контракт API не менялся, зависимостей нет. Все вызовы — через `backend` из `backend.ts`.

## Как проверить
`cd miniapp && VITE_MOCK=1 npm run dev`, затем:
1. `/form` — отправить анкету (например, навыки «керамика, работа с детьми», Москва, будни утро/день).
2. `/admin/opportunities` → «Создать возможность» → роль «Помощник на мастер-классе» → дата, мест 2, часов 2,5 → «Создать».
3. В карточке «Подобрать волонтёров» → отметить нового волонтёра → «Пригласить выбранных».
4. `/me` — блок «Вас пригласили» → `/opportunities` → «Подтвердить участие».
5. `/admin/opportunities/<id>` → «Участвовал» → у волонтёра в `/history` видно «+2,5 ч» и сумму.
Проверено руками на 375px (волонтёр) и 1280/1024px (`/admin`). Сброс демо-данных: очистить localStorage.

## Что осталось и на что обратить внимание
- На живом бэкенде не проверено — каталог (T-22) делает fry-alt. Экраны ждут эндпоинты из контракта как есть;
  отдельного `GET /opportunities/{id}` нет, карточка берёт возможность из общего списка.
- Шапка подбора в `Search.tsx` ведёт «← Возможности» на список, а не в карточку (не трогал, T-08).
- «Участвовал» у уже отмеченного участника не показываем, чтобы не начислить часы дважды; отменить отметку из UI нельзя.
