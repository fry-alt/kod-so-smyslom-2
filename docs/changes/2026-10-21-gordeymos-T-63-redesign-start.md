# Редизайн, шаг 1: палитра «Мята», новые шрифты и стартовый экран со сценами волонтёров

## Что изменилось
- Новая палитра «Мята» для всего сайта и кабинета фонда: светлый фон, глубокий зелёный акцент, солнечно-жёлтый и коралловый для иллюстраций. Цвета панели браузера и PWA — тоже зелёные.
- Шрифты: Unbounded — заголовки, Onest — текст (оба с хорошей кириллицей, подключены с Google Fonts).
- Стартовый экран волонтёра (`/`): заголовок «Станьте волонтёром творческих мастерских», одна главная кнопка «Заполнить анкету» и 4 анимированные сцены по направлениям, которые фонд сам называет: помощь на мастер-классах, наставничество (значимый взрослый), помощь специалистов (психолог, логопед, юрист), ярмарки и фото. Ниже — ближайшие занятия, где нужны люди (если их нет — неделя «когда нужна помощь»), «Как всё устроено», блок о фонде.
- Новый знак в шапке вместо эмодзи 🧡.
- Анимации короткие, только `transform`/`opacity`; при «уменьшении движения» в системе выключаются. Видимый фокус клавиатуры для всех элементов.

## Где в коде
- `miniapp/src/index.css` — токены палитры (`--p-*` → классы `bg-page`, `bg-accent`, `bg-pop`, `font-display`…), анимации `tile-in` и `anim-*`.
- `miniapp/src/screens/volunteer/Welcome.tsx` — стартовый экран.
- `miniapp/src/screens/volunteer/VolunteerScenes.tsx` — 4 сцены: персонажи из простых SVG-фигур, цвета — из палитры.
- `miniapp/src/App.tsx` — шапка со знаком, широкая раскладка только для стартового экрана.
- `miniapp/index.html` — шрифты, `theme-color`.
- Контракт и бэкенд не менялись, npm-зависимостей нет.

## Как проверить
`VITE_MOCK=1 make dev-miniapp` → http://localhost:5173 (в Mini App или в обычном браузере без анкеты). Ширина 375 / 1024 / 1280px — без горизонтальной прокрутки. В системных настройках включить «уменьшение движения» — сцены стоят. `npm run build` проходит.

## Что осталось и на что обратить внимание
- Остальные экраны пока в старой вёрстке, но уже в новых цветах и шрифтах — следующие шаги T-63.
