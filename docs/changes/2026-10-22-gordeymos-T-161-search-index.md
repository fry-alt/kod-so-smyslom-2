# Умный поиск не падает с 500, если волонтёра нет в векторном индексе

## Что изменилось
- На проде `POST /search` отвечал 500 на любой запрос. Причина: части волонтёров (например, 1, 42, 45) не было в Chroma-коллекции
  `volunteers_*`, а Chroma 1.5.9 на любой отсутствующий id в `query(ids=…)` падает с `InternalError: Error finding id`.
  Поиск ловил только `LLMError`, поэтому вместо фолбэка — 500. Воспроизвёл из кабинета координатора: в выборке только 46 — 200, с 45 — 500.
- Теперь в Chroma спрашиваем только тех, кто есть в индексе. Остальные всё равно в выдаче — их оценивает LLM или фолбэк по навыкам.
- Любая ошибка Chroma в поиске — как недоступные эмбеддинги: ищем без векторов, а не отвечаем 500.
- При старте бэкенда в фоне добавляем в индекс волонтёров, которых там нет: анкеты, у которых эмбеддинг не получился при сохранении,
  и все анкеты после смены провайдера эмбеддингов. Раньше «переиндексация позже» из ARCHITECTURE.md нигде не делалась.

## Где в коде
- `backend/app/services/volunteer_index.py` — новая `indexed(ids)`; `nearest()` запрашивает только проиндексированных.
- `backend/app/services/search.py` — `vector_similarity()` ловит `chromadb.errors.ChromaError` → пустой словарь (фолбэк).
- `backend/app/services/volunteers.py` — `index_missing()`: недостающие в индекс, ошибка не роняет бэкенд.
- `backend/app/main.py` — `index_missing()` в фоновом потоке при старте, как `autoload_documents()`.
- `docs/ARCHITECTURE.md` — две строки про переиндексацию. Контракт API, таблицы и переменные окружения не менялись.

## Как проверить
- `make lint && make test` — проходят; в `test_search.py` 4 новых теста: волонтёра нет в индексе, индекс сломан,
  `index_missing()` добавляет только недостающих, `index_missing()` переживает недоступные эмбеддинги.
- На проде после деплоя: в логе бэкенда «Добавили в индекс волонтёров: N»; `/admin/search` → любой пример → карточки, а не
  «Сервер сейчас не отвечает».

## Что осталось и на что обратить внимание
- Доиндексация идёт в фоне: первые секунды после старта у недостающих анкет нет векторов, но поиск уже отвечает.
- Если эмбеддинги при старте недоступны, недостающие добавятся только при следующем запуске бэкенда.
