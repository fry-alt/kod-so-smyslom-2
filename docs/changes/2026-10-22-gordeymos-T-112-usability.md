# Исправления по юзабилити-аудиту в пути волонтёра и кабинете фонда

## Что изменилось

- Исправлены подписи вопросов анкеты, прокрутка клавиатурного фокуса, контраст полей и элементов, поведение анимаций.
- После регистрации пользователь возвращается к анкете; кнопка входа открывает форму входа.
- Путь волонтёра и воронка координатора приведены к одному порядку. В кабинете волонтёра виден следующий шаг.
- В умном поиске видны статус ожидания и действие приглашения на возможность.
- При входе роль определяется аккаунтом. Для забытого пароля добавлена временная ссылка на координатора в Telegram.
- В обучении выделен следующий обязательный модуль; после теста показывается правильный ответ. В сообщениях Enter вставляет перенос строки.
- Добавлены заголовки вкладок и упрощён экран благодарности после анкеты.

## Где в коде

Изменены экраны анкеты, входа, поиска, обучения, кабинета, сообщений и общие стили Mini App. Контракт результата теста дополнен индексами правильных вариантов, которые сервер возвращает только после отправки ответов; синхронно обновлены `backend/app/schemas.py` и `miniapp/src/api.ts`.

## Как проверить

- `cd miniapp && npm run build` — успешно.
- `make lint` — успешно (ruff check, ruff format --check, TypeScript typecheck).
- Синтаксис изменённых Python-файлов проверен через `ast.parse`.
- `git diff --check` — успешно.
- Локальный просмотр: `VITE_MOCK=1 npm run dev` (данные вымышленные).
- Автотесты локально не запускались.
