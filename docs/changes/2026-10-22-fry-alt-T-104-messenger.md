# «Сообщения» волонтёра — как мессенджер: слева чаты по откликам, справа переписка

## Что изменилось
- На `/messages` нет подвала. Окно чатов — на высоту экрана, прокручивается только переписка внутри.
- Слева список чатов: «Координатор фонда» (всегда первый, для любых вопросов) и по одному чату на каждый отклик —
  с датой занятия вместо аватарки, последним сообщением, временем и счётчиком новых. Где свежее сообщение — те выше.
- Справа открытый чат: в шапке занятие, дата и статус отклика («Вы записаны», «Вас приглашают»…), над сообщениями — день
  («Сегодня», «Вчера»), поле растёт по мере набора, рядом круглая кнопка отправки. В пустом чате — готовые вопросы
  («Что взять с собой?»), по нажатию текст попадает в поле.
- На телефоне видно что-то одно: список или чат со стрелкой «←». «Написать координатору» с карточки занятия, как и раньше,
  ведёт на `/messages?about=<id>` — теперь это сразу чат этого занятия.
- Координатор в `/admin/messages`: ответ по умолчанию помечается тем же занятием, что и последнее сообщение, — иначе
  у волонтёра он попал бы в общий чат. Пометка видна над полем, её можно снять крестиком. Это меняет поведение
  из заметки T-100 (`2026-10-22-fry-alt-T-100-chat.md`), где тема сбрасывалась после каждой отправки.

## Где в коде
- `miniapp/src/screens/volunteer/Messages.tsx` — новый экран: список чатов, открытый чат, поле ввода. Чаты собираются
  на сайте из одной переписки (T-100) по `opportunity_id` сообщения и из откликов волонтёра (`myParticipations`).
- `miniapp/src/messages/Thread.tsx` — теперь только для координатора; оттуда экспортируются пузырь сообщения, время
  и константы. Тема ответа «как в последнем сообщении».
- `miniapp/src/App.tsx` — у `/messages` своя раскладка: высота экрана, без подвала.
- `miniapp/src/index.css` — «обои» чата в горошек и появление нового сообщения.
- `miniapp/src/mock.ts` — в демо-переписке приветствие в общем чате, ответ Марии привязан к керамике.
- Контракт API, бэкенд и БД не менялись. Новых зависимостей нет.

## Как проверить
- `make dev-miniapp` с `VITE_MOCK=1`, в консоли браузера `localStorage.setItem("volunteer_id", "3")`, открыть `/messages`:
  два чата, у керамики — переписка по дням; отправить сообщение — оно появится в этом чате и в превью слева.
- Узкое окно (телефон): сначала список, по нажатию — чат, «←» возвращает к списку.
- `/messages?about=2` — чат занятия без сообщений, с готовыми вопросами.
- `make lint && make test` проходят. Тестов фронта в проекте нет — проверено в браузере.

## Что осталось и на что обратить внимание
- «Прочитано» на сервере ставится сразу на всю переписку: значок в меню кабинета гаснет, как только волонтёр открыл
  любой чат с новыми. Счётчики в списке чатов гаснут по одному — пока страница открыта.
- Старые ответы волонтёра без пометки «о занятии» (написанные до этой задачи) лежат в общем чате «Координатор фонда».
