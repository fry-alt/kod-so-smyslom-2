# Анкета → профиль через LLM → векторный индекс, без персональных данных

## Что изменилось
- `POST /volunteers` теперь возвращает заполненный `profile`: навыки, интересы, подходящие роли из `data/roles.json`, одна фраза для координатора. Раньше (T-01) профиль был пустым.
- Каждый волонтёр попадает в векторный индекс — по нему будет работать умный поиск (T-06).
- Если LLM недоступна или ответила мусором — анкета всё равно сохраняется, `profile: null`, в индекс попадают одни ответы анкеты.
- Смена статуса (`PATCH /volunteers/{id}`) обновляет его и в индексе.
- Имя, контакт, `telegram_id` и заметки координатора не уходят ни в LLM, ни в эмбеддинги, ни в индекс — это проверяет тест.

## Где в коде
- `backend/app/llm/prompts/profile.md` — промпт с двумя примерами; переменные `$roles` (`code: title`) и `$answers`.
- `backend/app/services/volunteers.py`:
  - `create()` — сохранить → `extract_profile()` → индекс;
  - `answers_text()` — ответы анкеты текстом, коды переведены в слова (словари `AVAILABILITY`, `REGION`, … пригодятся в T-06);
  - `index_document()`, `index_metadata()` — что кладём в индекс.
  - Коды ролей, которых нет в справочнике, отбрасываются.
- `backend/app/services/volunteer_index.py` — `upsert()` и `update_metadata()` поверх Chroma.
- `backend/app/rag/store.py` — `get_collection(kind="docs" | "volunteers")`; старые вызовы без аргумента работают как раньше.
- Индекс: коллекция `volunteers_<бэкенд эмбеддингов>`, id = id волонтёра. Metadata: `status`, `occupation`, `region`, `regularity` — строки; `availability`, `formats` — списки (фильтр `$contains`), пустой список не пишем — Chroma его не принимает.
- Контракт, таблицы БД, зависимости и переменные окружения не менялись.

## Как проверить
- `make dev`, `make seed` → у всех 40 волонтёров есть `profile` (на `fake` — заглушка по схеме, `suitable_roles` пустые).
- `make test` — `backend/tests/test_volunteer_profile.py`: профиль строится, в промпте ответы и роли, неизвестные роли отбрасываются, анкета сохраняется при падении LLM, содержимое индекса, PATCH обновляет индекс, персональные данные никуда не уходят.
