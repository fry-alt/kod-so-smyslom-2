# «Спроси о фонде»: документы «Детей Марии» в базе знаний, промпт «коротко + источник + честное не знаю»

## Что изменилось
- В `data/demo/` вместо документов вымышленного фонда «Соседи рядом» из шаблона теперь демо-документы
  «Детей Марии»: о фонде, правила волонтёра, частые вопросы новичка, мероприятия, расписание занятий,
  памятка мастерской, данные волонтёров, как ещё помочь. Общие факты — из `docs/CASE.md`,
  детали (телефоны, почта, расписание) вымышлены и помечены в каждом файле. Это то, о чём просила заметка T-03.
- `make ingest` загружает и документы фонда (`data/demo`), и учебные тексты (`data/training`).
- Ответ на `/documents/ask` — 1–3 предложения простым языком, всегда с источником. Нет ответа в документах —
  «Не знаю: в документах фонда этого нет. Спросите координатора.»
- Если LLM недоступна, вопрос не падает с 502: ответ «не получилось составить ответ» и два подходящих
  фрагмента документов (`found=false`, `sources` не пустой).
- 10 типовых вопросов новичка с ожидаемыми источниками и скрипт прогона.

## Где в коде
- `backend/app/llm/prompts/rag_answer.md` — новые правила и два few-shot примера (ответ есть / ответа нет).
- `backend/app/rag/answer.py` — текст `NOT_FOUND`, при `found=false` всегда он (а не текст модели),
  фолбэк `LLM_FAILED` на `LLMError`.
- `backend/app/rag/ingest.py` — у `.md` отрезается шапка `---`…`---` (title/required учебных модулей).
- `scripts/ingest.sh` — принимает несколько папок; `Makefile` (`ingest`), `README.md`.
- `data/demo/rag_questions.json` — 10 вопросов: 8 с ответом в документах, 2 без.
- `scripts/rag_check.py` — задаёт вопросы работающему бэкенду, печатает ответ, источники и «Итого N из 10».
- `data/demo/`: удалены `annual_report_2025.docx`, `help_request.md`; добавлен `workshop_guide.docx`;
  переписаны `about_fund.md`, `volunteer_rules.md`, `faq.md`, `privacy_policy.md`, `donations.txt`,
  `events.csv`, `volunteer_shifts.xlsx`. Контракт API не менялся.

## Как проверить
```bash
make dev            # в одном терминале
make ingest         # в другом: 12 файлов
uv run python scripts/rag_check.py
```
`make test` — `backend/tests/test_rag.py`: чтение всех форматов, учебные тексты без шапки, по 10 вопросам
поиск кладёт в контекст нужный файл (на fake — 8 из 8, тест требует от 7), ответ ссылается на фрагмент из
контекста, «нет ответа» от модели → `NOT_FOUND` без источников, пустая база → `NOT_FOUND`,
LLM упала → фрагменты вместо 502.

**Реальной LLM нет**: в `.env` стоит `LLM_PROVIDER=fake`, ключа нет. Прогон `rag_check.py` на fake —
**5 из 10**, и это предел fake, а не поиска: fake-модель всегда ссылается на фрагмент [1] и никогда не
говорит «не знаю». Поиск при этом даёт нужный файл в контексте для всех 8 вопросов с ответом.
Сколько из 10 даст настоящая модель — нужно прогнать `rag_check.py` с ключом (T-13).
