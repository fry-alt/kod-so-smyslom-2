# T-26: выкладка удаляет старые неиспользуемые образы Docker на сервере

## Что изменилось
- Перед загрузкой наших образов: `docker image prune -af --filter until=48h` — удаляются образы старше 2 дней,
  которые не запущены. Запущенный Yapp и его откатные образы за последние 2 дня остаются.
- Удаляются и наши прошлые `deti-python`/`deti-miniapp`, если они не запущены (например, недозагруженные).

## Зачем
Прошлая выкладка снова упала с `no space left on device`. Диск сервера 14 ГБ, из них 6,4 ГБ — 200 образов Docker,
запущено только 5: при каждой выкладке Yapp копились его старые версии. Наш Python-образ весит 1,77 ГБ, а при
загрузке нужно примерно вдвое больше. Решение согласовано с владельцем сервера.

## Где в коде
`.github/workflows/deploy.yml`, шаг «Образы и данные на сервер».

## Как проверить
В логе шага `df -h /` после очистки показывает несколько гигабайт свободно, Deploy зелёный,
`https://deti.201-34-157-90.sslip.io/api/health` отвечает.

## Что осталось и на что обратить внимание
- Откатить Yapp на версию старше 2 дней теперь нельзя (образа нет) — только пересборкой.
- Python-образ можно облегчить (1,77 ГБ): streamlit нужен только для /demo.
