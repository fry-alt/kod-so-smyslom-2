# «Забыли пароль?» — сброс пароля кодом на почту

## Что изменилось
- На странице входа — «Забыли пароль?»: почта → на неё приходит код → код и новый пароль → человек сразу в кабинете.
  Перенесено из Yapp (`requestReset`/`finishReset`), правила те же, что у кода при регистрации: 15 минут, 5 попыток,
  повтор через минуту, действуют три последних кода.
- Ответ на запрос кода одинаковый, есть такой аккаунт или нет, а письмо уходит уже после ответа — по сайту нельзя
  узнать, кто зарегистрирован.
- После смены пароля меняется ключ входа: на других устройствах придётся войти заново. Старый пароль не подходит.
- Если на сервере не настроена почта (Postbox), сброс отвечает «Сбросить пароль пока нельзя — напишите координатору».
  Ссылка на координатора в Telegram из T-112 (`2026-10-22-gordeymos-T-112-usability`) осталась — теперь на шаге
  «Забыли пароль?» («Письмо не приходит?»).

## Где в коде
- `backend/app/services/email_codes.py` — у кода появилась цель (`signup` | `reset`), `request_reset`,
  `send_reset_letter`, `finish_reset`; письмо для сброса со своим текстом.
- `backend/app/models.py` — `EmailCode`: ключ (почта, цель), таблица `email_codes`. Старая `emailcode` (из T-111)
  больше не используется: коды живут 15 минут, переносить нечего; удалять её не обязательно.
- `backend/app/services/accounts.py` — `set_password` (новый хэш и новый ключ входа).
- **Контракт API:** `POST /auth/reset {email}` → `CodeSent`; `POST /auth/reset/confirm {email, code, password}` →
  `AuthOut`. `miniapp/src/api.ts` — `ResetConfirmIn`, `authApi.reset/resetConfirm`.
- `miniapp/src/screens/Auth.tsx` — `ForgotStep` (почта), `CodeStep` с целью `reset` (ячейки кода + новый пароль),
  поле пароля вынесено в `PasswordInput`. `miniapp/src/mock.ts` — сброс в моках, код `123456`.

## Как проверить
- `make test` — `backend/tests/test_email_codes.py`: сброс с кодом (старый пароль и старый ключ входа больше не
  работают), короткий пароль не тратит попытку, одинаковый ответ для несуществующей почты, коды регистрации и сброса
  не подходят друг к другу, без почты на проде — 503.
- Локально: `/login` → «Войти» → «Забыли пароль?» → почта → код в логе бэкенда → новый пароль → личный кабинет.
  Проверено в браузере на компьютере и на ширине телефона.
