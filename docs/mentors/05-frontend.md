# Фронтенд: одно приложение для сайта, Telegram Mini App, кабинета фонда и Android

`miniapp/` — React 19 + TypeScript + Vite + Tailwind 4. Других runtime-зависимостей нет, кроме Capacitor для APK:
маршрутизация, markdown, графики, 3D-эффекты и док-меню написаны сами, коротко и с комментариями.
Интерфейс крупный и простой: среди волонтёров есть пенсионеры, координатор не айтишник.

## 1. Устройство

| Файл | Что делает |
|---|---|
| `main.tsx` | старт: `initTelegram()`; если открыто в Mini App и анкета не запомнена — спрашивает бэкенд по подписи Telegram (`byTelegram`, не дольше 3 с); из бота кто уже заполнил анкету — сразу в `/me` |
| `App.tsx` | таблицы маршрутов `VOLUNTEER_ROUTES` и `ADMIN_ROUTES`, раскладки, шапка. Кабинет фонда, страница звонка и тяжёлые экраны грузятся лениво (`lazy`): волонтёру они не нужны |
| `router.ts` | роутер без библиотек: `usePath()` на `useSyncExternalStore` + `popstate`, `navigate()` через `history.pushState`, `match("/admin/volunteers/:id", path)` |
| `api.ts` | **контракт** (типы — зеркало `backend/app/schemas.py`) и клиент: `post`/`request` добавляют `Authorization: Bearer <token>` и `X-Telegram-Init-Data`; ошибка → `Error` с `detail` бэкенда, понятным человеку |
| `backend.ts` | единая точка входа для экранов: настоящий API или моки (`VITE_MOCK=1`). Сессия в `localStorage`: ключ входа, аккаунт, id анкеты, оформление |
| `mock.ts` | моки по тому же контракту. С ними трек B делал интерфейс раньше, чем появлялись эндпоинты |
| `telegram.ts` | минимальная типизация Telegram WebApp SDK; цвета темы Telegram → CSS-переменные |
| `labels.ts` | все подписи для значений контракта («weekday_morning» → «будни утром», статусы, цвета меток) |
| `ui.tsx` | общие элементы: кнопки, ссылки, `useLoad` (загрузка, ошибка, повтор), выпадающий список с клавиатурой, чипсы, ошибки с `aria-describedby` |

Адрес API всегда относительный — `/api`. В dev его проксирует Vite (`vite.config.ts`, включая WebSocket звонка),
в Docker и на проде — Caddy внутри контейнера `miniapp`. Поэтому нет CORS и разных адресов. Исключение — Android:
приложение открывается из файлов APK и ходит по полному адресу (`PROD_API` в `vite.config.ts`).

## 2. Как приложение узнаёт человека

| Где | Как |
|---|---|
| Сайт | вход по почте и паролю → ключ в `localStorage` → заголовок `Authorization` |
| Telegram Mini App | подписанная строка `initData` → заголовок `X-Telegram-Init-Data`, бэкенд проверяет подпись. Можно и без регистрации по почте |
| Кабинет фонда | только аккаунт с ролью `coordinator`. Иначе `/admin` показывает вход с выбранной ролью «координатор» |

Анкету сервер отдаёт только её хозяину. Если на устройстве остался номер анкеты, а входа нет, он забывается при старте.

## 3. Экраны волонтёра

| Путь | Экран | Что внутри |
|---|---|---|
| `/` | `Welcome.tsx` | лендинг: анимированные сцены «что делают волонтёры» (`VolunteerScenes.tsx`, фигуры на SVG), ближайшие занятия с 3D-наклоном карточек (только мышь), «как всё устроено» (`Journey.tsx`) |
| `/login` | `Auth.tsx` | вход и регистрация (волонтёр или координатор), код из письма, «Забыли пароль?»; ошибка поля — фокус и `aria-invalid` |
| `/form` | `Form.tsx` | пошаговая анкета: вопросы фонда дословно + «Когда и где удобно»; черновик и шаг в `localStorage`; подсказки навыков по ролям фонда; в конце «Проверьте ответы» |
| `/me` | `Me.tsx` | личный кабинет: шапка с аватаром, главный следующий шаг, путь волонтёра, приглашения, «Моя помощь» (`MyHelp.tsx`: часы, график по месяцам, история), собеседование, оформление (`Look.tsx`) |
| `/training` | `Training.tsx`, `training/*` | дорожка модулей, кольцо прогресса, чтение (`Markdown.tsx` — свой парсер под то, что пишет фонд), тест по одному вопросу и разбор (`QuizView.tsx`) |
| `/interview` | `Interview.tsx` | запись на собеседование: свободное время, запись, перенос, отмена, «Войти в звонок» |
| `/opportunities` | `Opportunities.tsx` | приглашения сверху, лента с «Подходит вам», отклик, «Не смогу», «Написать координатору» |
| `/messages` | `Messages.tsx` | мессенджер: чат «Координатор фонда» + чат по каждому отклику; опрос раз в 5 секунд, пока вкладка видна |
| `/ask` | `Ask.tsx` | помощник по документам: примеры вопросов, ответ с раскрывающимися источниками |

## 4. Кабинет фонда (`/admin`)

Меню — плавающий «док» (`AdminDock.tsx`): иконка под курсором увеличивается, как в macOS. На телефоне,
при сенсорном вводе и при «уменьшении движения» эффекта нет.

| Путь | Экран | Что внутри |
|---|---|---|
| `/admin` | `Summary.tsx` | «Сводка»: цифры, собеседования сегодня, новые анкеты, ждут допуска, отклики, нехватка людей (места кружками) |
| `/admin/search` | `Search.tsx` | умный поиск: запрос словами или роль; «Как я понял запрос» с правкой условий; кандидаты; с `?opportunity=` — подбор под занятие и «Пригласить выбранных» |
| `/admin/volunteers` | `Volunteers.tsx` | база: таблица на ноутбуке, карточки на телефоне, фильтр по статусу, сортировка, «Скачать часы для Excel» |
| `/admin/volunteers/:id` | `VolunteerCard.tsx` | статус, часы, благодарность, обучение, собеседование, профиль от AI, ответы анкеты (`interview/InterviewBlock.tsx`, `Plan.tsx`, `ResultForm.tsx`) |
| `/admin/opportunities`, `/new`, `/:id` | `Opportunities.tsx`, `OpportunityForm.tsx`, `OpportunityCard.tsx` | занятия: создать из роли, участники и действия по статусу, «Подобрать волонтёров» |
| `/admin/analytics` | `Analytics.tsx` | воронка, спрос и предложение, недели, топ, «засыпающие»; графики — обычные блоки с шириной в процентах, без библиотек |
| `/admin/messages` | `Messages.tsx` + `messages/Thread.tsx` | все переписки, открытая переписка; Enter — новая строка, Ctrl/Cmd+Enter — отправить |
| `/admin/settings` | `Settings.tsx` | код фонда |

## 5. Видеозвонок — `miniapp/src/call/`

| Файл | Что делает |
|---|---|
| `CallScreen.tsx` | `/call/<token>`: роль по параметру `?as=coordinator`, иначе волонтёр. `GET /calls/{token}` → статус и ICE-серверы. «Прихожая»: камера включается сразу, чтобы человек видел себя; индикатор микрофона; «Войти в звонок». Тексты для отменённого и прошедшего звонка, «Переподключиться». После «Завершить звонок» у координатора по центру открывается итог |
| `room.ts` | класс `Room` — WebRTC, перенесён из нашего прошлого проекта Yapp. WebSocket к `/api/calls/<token>/ws` → `join` → при `joined` звонит тем, кто уже в комнате. **Звонит тот, кто вошёл позже**, поэтому встречных предложений не бывает. ICE-кандидаты, пришедшие раньше SDP, копятся в очереди. Нет своей камеры — `recvonly`, чтобы всё равно видеть собеседника. Соединение `failed` → `restartIce()`. WebSocket оборвался → переподключение с паузой 1, 2, 4 … 10 с |
| `getLocalMedia` | камера и микрофон с шумоподавлением; нет камеры — только звук; нет ничего — понятный текст, что разрешить |
| `parts.tsx` | раскладка, видео с заглушкой вместо чёрного прямоугольника, крупные кнопки с подписями, индикатор громкости (Web Audio, звук никуда не уходит) |
| `CoordinatorPanel.tsx` | панель «План / Итог» справа (на телефоне — под звонком). Открывается по ссылке из кабинета с `interview` и `volunteer` в адресе. Имя волонтёра на странице звонка не показывается |

## 6. Доступность и детали

- Крупный шрифт, крупные кнопки с подписями, простой язык без жаргона.
- `prefers-reduced-motion` выключает все анимации: сцены, 3D, док, переходы входа.
- Ошибки форм связаны с полями (`aria-describedby`), первая ошибка получает фокус и прокручивается в видимую область.
- Свой выпадающий список работает с клавиатуры: стрелки, Home/End, Enter, Esc.
- PWA: `public/manifest.webmanifest` и иконки — сайт ставится «на экран Домой».
- Внутри Telegram используется системная кнопка «Назад» (`tg.BackButton`), цвета берутся из темы Telegram.

## 7. Сборка и проверки

```bash
cd miniapp
npm run dev            # :5173
npm run typecheck      # tsc --noEmit (входит в make lint)
npm run build          # tsc + vite build → dist/
VITE_MOCK=1 npm run dev  # без бэкенда, на моках
npm run build:android  # сборка для APK + cap sync android
```
