# Для менторов: как устроен проект и как его проверить

Кейс 3 хакатона «Код со смыслом 2»: **«Дети Марии» — единое пространство для волонтёров с умным подбором**.
Команда из двух человек: A — бэкенд и AI (fry-alt), B — интерфейс и деплой (gordeymos).

Главная функция — **умный поиск волонтёров для координатора фонда**. Координатор пишет запрос
обычными словами («фотограф на субботу в Москве, разово») и сразу получает топ кандидатов:
оценку, объяснение «почему подходит», статус обучения и историю участия. Вокруг поиска
собран весь путь волонтёра: анкета → обучение с тестом → видеособеседование → занятия → часы и благодарность.

## Проверка за 10 минут

```bash
make setup          # зависимости, .env, служебный ключ, git-хуки
```
В `.env` впишите `COORDINATOR_CODE=1111` (любой код: без него регистрация координатора закрыта).

```bash
make dev            # терминал 1: бэкенд :8000
make dev-miniapp    # терминал 2: сайт :5173
make seed           # терминал 3: 40 демо-анкет, 8 занятий и история для дашбордов
make test           # 277 тестов, без сети и ключей
```

1. http://localhost:5173/login → «Регистрация» → «Я координатор» → код `1111`. Код подтверждения
   почты локально печатается **в терминале бэкенда** (письма не уходят).
2. `/admin` → «Умный поиск» → «нужен фотограф на четверг утром». Видно, как система поняла запрос, и топ кандидатов.
3. Карточка любого волонтёра → «Собеседование» → «Назначить» → «Открыть звонок». Ссылку для волонтёра
   откройте во втором окне (инкогнито): получится видеозвонок между двумя вкладками. Подробно — в [02-scenarios.md](02-scenarios.md#5-видеособеседование).

Без ключей всё работает на провайдере `fake`: AI-ответы помечены «[fake]», а поиск идёт по
векторам и навыкам. Как подключить YandexGPT — в [01-run.md](01-run.md#8-настоящий-llm).

## Карта репозитория

```
backend/app/
  main.py          FastAPI: роутеры, CORS, ошибки LLM → 502, фоновые задачи при старте
  config.py        все настройки из .env (pydantic-settings)
  db.py, models.py SQLite через SQLModel: 17 таблиц
  schemas.py       контракт API (pydantic), зеркало — miniapp/src/api.ts
  api/             HTTP-обёртки без логики, проверка доступа
  services/        вся логика: анкета, поиск, обучение, занятия, собеседования, переписка, дашборды…
  llm/             единый клиент LLM, провайдеры (fake, Yandex, GigaChat, OpenAI-совместимые, Anthropic), промпты
  rag/             документы фонда → чанки → Chroma → гибридный поиск → ответ с источниками
backend/tests/     pytest, провайдер fake, без сети
bot/               Telegram-бот на aiogram 3, ходит только в бэкенд
miniapp/           React 19 + Vite + Tailwind: сайт, Mini App, кабинет фонда, страница звонка, Android (Capacitor)
web/               Streamlit-демо из шаблона (чат и документы)
data/              роли фонда, учебные модули, демо-анкеты и документы (всё вымышленное)
scripts/           seed, ingest, smoke, benchmark, проверки помощника
deploy/, docker/   Docker Compose, Caddy, выкладка на сервер
```
